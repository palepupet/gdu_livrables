# Titre professionnel CDA - Dossiers de soutenance

Documents préparés pour le passage du titre professionnel **Concepteur Développeur d'Applications**, à la suite de ma formation chez **Global Digital University** (2026).

Le projet présenté est **TaskFlow Manager** : une API REST en Symfony et une application web en React qui la consomme.

## Contenu du dépôt

| Document | Description |
|---|---|
| Taskflow-manager.pdf | Support de la présentation orale du projet |
| dossier_professionnel.pdf | Mise en œuvre de chaque compétence du titre (partie front-end et partie back-end) |
| dossier_projet.pdf | Présentation complète du projet TaskFlow Manager |
| livret_ecf_CDA.pdf | Évaluations réalisées pendant la formation |

## Le projet TaskFlow Manager

- **API** (PHP 8.2, Symfony 7, Doctrine, MySQL, JWT) : [gdu_taskflow_manager_api](https://github.com/palepupet/gdu_taskflow_manager_api)
- **Application web** (React 19, Vite, Material UI) : [gdu_taskflow_manager_web](https://github.com/palepupet/gdu_taskflow_manager_web)
- **Application en ligne** : https://gdu-taskflow-manager-web.onrender.com
- **Documentation de l'API** : https://gdu-taskflow-manager-api.onrender.com/api/doc
